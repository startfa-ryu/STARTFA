# FAmiCal Custom Theme

ธีม WordPress สำหรับ startfa.com: หน้าแรกเป็น Landing Page / Content Hub ที่ส่งผู้ใช้ไป FAmiCal (famical.startfa.com) ส่วนบทความเดิมทั้งหมดยังเปิดได้ที่ URL เดิม

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `style.css` | ข้อมูลธีม + ดีไซน์ทั้งหมด (Responsive) |
| `functions.php` | เปิดใช้ฟีเจอร์ธีม, โหลด CSS/JS, เมนู Customizer "FAmiCal" |
| `header.php` | ส่วนหัว + ปุ่ม "เปิด FAmiCal" + เมนูมือถือ |
| `front-page.php` | หน้าแรก: Hero → Features/Tools → Testimonials → Blog |
| `footer.php` | ส่วนท้าย + CTA ปิดท้าย |
| `index.php` | แสดงบทความเดี่ยว/หน้า/หมวดหมู่/ค้นหา/404 (WordPress บังคับต้องมี) |
| `template-parts/content-card.php` | การ์ดบทความ |
| `comments.php` | ความคิดเห็น |
| `assets/js/navigation.js` | เมนูมือถือ (ไม่ใช้ jQuery) |

## วิธีติดตั้ง
1. **สำรองข้อมูลก่อน**: ใช้ปลั๊กอิน UpdraftPlus หรือระบบ Backup ของโฮสต์ สำรองทั้งไฟล์และฐานข้อมูล
2. **บีบไฟล์**: บีบโฟลเดอร์ `famical-custom-theme` เป็น `famical-custom-theme.zip` (ใน zip ต้องมีโฟลเดอร์นี้อยู่ชั้นบนสุด)
3. **อัปโหลด**: ไปที่ หน้าควบคุม → รูปแบบ (Appearance) → ธีม → เพิ่มใหม่ → อัปโหลดธีม → เลือก zip → ติดตั้ง
   (หรืออัปโหลดโฟลเดอร์ผ่าน FTP / File Manager ไปที่ `wp-content/themes/`)
4. **ดูตัวอย่างก่อนเปิดจริง**: กด "แสดงตัวอย่างสด" (Live Preview) ยังไม่ต้องกดเปิดใช้งาน
5. **ตั้งค่าใน Customizer** (ปรับแต่ง → FAmiCal):
   - Hero & ลิงก์ FAmiCal: พาดหัว, คำอธิบาย, ข้อความปุ่ม, URL ของ FAmiCal
   - รีวิวจากผู้ใช้งาน: **แทนข้อความตัวอย่างด้วยรีวิวจริง** (ช่องที่ว่างจะไม่แสดง ถ้าว่างทั้งหมดส่วนนี้จะถูกซ่อน)
   - Site Identity: อัปโหลดโลโก้
6. **เปิดใช้งาน (Activate)** ธีม
7. **เมนู**: รูปแบบ → เมนู → กำหนดเมนูให้ตำแหน่ง "เมนูหลัก (Header)" และ "เมนูส่วนท้าย (Footer)"
8. **วิดเจ็ต**: รูปแบบ → วิดเจ็ต → ใส่วิดเจ็ตเดิม (เรื่องล่าสุด, ความเห็นล่าสุด, ค้นหา) ใน "Sidebar บทความ"
9. **(แนะนำ) หน้ารวมบทความ**: สร้างเพจชื่อ "บทความ" (ว่างเปล่า) → การตั้งค่า → การอ่าน → เลือก "หน้าคงที่" หน้าแรก = เพจใดก็ได้ (เช่น "หน้าแรก"), หน้าบทความ = "บทความ"
   ปุ่ม "ดูบทความทั้งหมด" จะลิงก์ไปหน้านี้
10. **ตรวจหลังเปิดใช้**:
    - เปิดบทความเดิม 3-5 ลิงก์ ต้องเปิดได้ที่ URL เดิม
    - การตั้งค่า → ลิงก์ถาวร (Permalinks) → กด "บันทึก" 1 ครั้ง (ไม่ต้องแก้อะไร) เพื่อรีเฟรช rewrite rules
    - ดู Page Source ว่า `<title>`, meta description, schema จาก Rank Math/Yoast ยังอยู่
    - ล้างแคช (WP Rocket / LiteSpeed / Cloudflare) ถ้ามี
    - ทดสอบความเร็วที่ https://pagespeed.web.dev/

## เรื่อง SEO
- ธีมไม่สร้าง `<title>` หรือ meta เอง ทั้งหมดผ่าน `wp_head()` ให้ Rank Math/Yoast คุม
- ไม่เปลี่ยน URL, slug, หมวดหมู่ หรือฐานข้อมูลบทความ
- หน้าแรกมี H1 เดียว (พาดหัว Hero) และลิงก์ภายในไปบทความล่าสุด + หมวดหมู่ยอดนิยม
- ถ้าเลือกหน้าแรกเป็นหน้าคงที่และหน้านั้นมีเนื้อหา เนื้อหาจะแสดงต่อท้ายหน้าแรก (ใช้เขียนข้อความ SEO เพิ่มได้)

## วัดผลทราฟิกไป FAmiCal
ทุกปุ่มที่ลิงก์ไป FAmiCal มี UTM ติดไปด้วย เช่น
`?utm_source=startfa.com&utm_medium=referral&utm_campaign=landing&utm_content=hero`
ดูใน Google Analytics ของ FAmiCal ได้ว่าคลิกมาจาก header / hero / tool-* / single-post / footer

## ข้อควรระวัง
- **โฆษณา AdSense / Google Analytics / Facebook Pixel**: ถ้าเดิมใส่โค้ดไว้ในธีมเก่า (header.php หรือช่องตั้งค่าธีม) โค้ดจะหายเมื่อเปลี่ยนธีม ให้ใส่ใหม่ผ่านปลั๊กอิน เช่น Site Kit by Google หรือ WPCode
- **Shortcode ของธีมเก่า**: ถ้าบทความเดิมใช้ shortcode เฉพาะของธีมเก่า จะแสดงเป็นข้อความดิบ ให้ตรวจบทความสำคัญก่อน
- **ปุ่มแชท / Chat widget**: ถ้ามาจากปลั๊กอินจะยังทำงาน ถ้าใส่ไว้ในธีมเก่าต้องใส่ใหม่
